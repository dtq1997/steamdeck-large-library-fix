# Steam Deck 大库体验优化插件

[![English](https://img.shields.io/badge/English-Switch-2563eb?style=for-the-badge)](README.md)

&#12288;&#12288;当 Steam 用户的库中游戏数目过多时，即使绝大多数游戏没有安装，登录 Steam Deck、从待机中唤醒或浏览游戏库时，也可能遭遇漫长的等待和严重卡顿。根源之一在于账号资料同步时，Steam 会反复对整个游戏库和合集进行筛选、排序与界面更新，使得大量计算集中在界面线程上，拖慢交互。常见的临时应对办法是开启[离线模式](https://github.com/ValveSoftware/steam-for-linux/issues/9956#issuecomment-1806394364)，或是在游戏界面中进入待机状态，让唤醒后至少能先继续游戏，等待 Steam 界面恢复。实际上，社区早在 [2022 年 4 月就有大库用户抱怨启动等待十几分钟](https://www.reddit.com/r/Steam/comments/uaxhc4/comment/i60yv91/)，2023 年又有[唤醒后界面冻结 30–60 秒的明确报告](https://github.com/ValveSoftware/steam-for-linux/issues/9956)。官方虽然推出过[针对大库的优化](https://store.steampowered.com/news/app/1675200/view/3220645457134651321)，但这类卡顿至今仍未彻底解决。本插件试图优化这一长期存在的大库体验问题。

## 下载和安装

1. 在 Steam Deck 上退出游戏，切换到**桌面模式**。
2. 从 GitHub 的 **[Releases](https://github.com/dtq1997/steamdeck-large-library-fix/releases)** 下载 `SteamDeck-LargeLibraryFix-0.4.16.desktop`。也可以在电脑下载后，把这个文件拷到 Deck 桌面上。
3. 打开这个文件。若出现系统安全确认，选择“信任并启动”“继续”或相应的执行选项。若系统只把它当成文本打开，右键文件 → 属性 → 权限，允许作为程序执行，再打开。
4. 看到“已安装”后，方便时正常重开 Steam，或重启 Deck，使补丁加载。

安装文件自带全部内容，不需要解压、联网安装或管理员密码。

## 优化内容

- 减少唤醒后资料同步的重复计算，缩短界面忙于更新游戏库的时间。
- 减轻切换标签、显示合集和连续向下浏览时的筛选、排序与绘制开销。
- 改善部分长按导航停住、滚动后焦点移出可见范围的问题。
- 避免商店资料请求长时间阻塞启动；不修改游戏、存档或合集定义。

当前为预览版，仍可能出现卡顿；实测基于一台约四万款游戏的 Deck，尚不能保证所有设备都有相同效果。

## 原理

插件在已识别的 Steam 界面代码中减少重复工作：复用未变化的游戏资料，让同一轮更新共用筛选结果，并让合集数量和封面预览只在相关资料改变时重新计算。同时调整部分导航与滚动逻辑，限制商店资料请求对初始化的等待时间。

补丁和原始备份保存在用户目录。游戏模式启动及相关文件变化时会按功能组检查兼容性，能识别排版和部分变量、类名变化；唤醒检查只涉及相关模型成员，减少无关辅助方法变化的影响。已验证的结果会复用，减少开机时的重复解析。兼容的优化被更新覆盖后会重新应用；相关逻辑发生变化时暂停对应组，查看状态可看到哪些项目生效、哪些暂停。未知改动仍可能需要新版适配，不会强行套用旧逻辑。

## 使用方式

打开桌面的 **Steam 大库优化**，选择：

- **查看状态**：检查磁盘上的当前 Steam 文件是否含兼容补丁。它不能证明尚未重开的界面已经加载。
- **检查更新**：查找 GitHub 新版，确认并校验下载后安装，保留原始备份；下载失败不会改动当前安装。
- **安装 / 修复此版本**：应用当前安装器所带的版本，不会联网获取新版本。
- **卸载并恢复**：移除自动检查，恢复仍与本工具修改记录一致的原文件。然后正常重开 Steam。
