# Steam Deck 大库优化

减少大型 Steam 游戏库在唤醒后更新资料、切换页面和向下浏览时的重复计算，并修复部分连续导航停住的问题。

An offline, reversible SteamOS library UI patch for large Steam libraries.

**0.4.16 预览版**：改进更新后的兼容检查、分组启停与恢复；当前已适配客户端保留 0.4.13 的全部性能优化。这是第三方工具，与 Valve 无关；目前完成了一台大库 Steam Deck 的有限实测，适合愿意保留回退的用户试用。

## 下载和安装

1. 在 Steam Deck 上退出游戏，切换到**桌面模式**。
2. 从 GitHub 的 **Releases** 下载 `SteamDeck-LargeLibraryFix-0.4.16.desktop`。也可以在电脑下载后，把这一个文件传到 Deck 桌面。
3. 打开这个文件。首次若出现系统安全确认，选择“信任并启动”或相应的执行选项。若系统只把它当成文本打开，右键文件 → 属性 → 权限，允许作为程序执行，再打开。
4. 看到“已安装”后，方便时正常重开 Steam，或重启 Deck，使补丁加载。

不需要解压、输入命令、管理员密码、Steam 账号密码或 API key。安装器自带全部安装内容，安装过程不联网；可以移动、重命名这个文件，安装成功后也可以删除它。

首次信任确认由 SteamOS 桌面处理，本工具不能跳过。请下载 Release 附件本身，不要把 GitHub 网页另存为安装文件。

安装器不会自动关闭 Steam、结束游戏或重启系统。桌面上会出现 **Steam 大库优化**（英文桌面显示 **Steam Library Fix**），用于查看状态、修复和卸载。

## 适合什么情况

- 游戏库很大，唤醒后 Steam 长时间忙于更新资料。
- 合集较多，切换标签、显示合集卡片或连续向下移动时明显卡顿。
- 希望保留完整游戏库、合集和原有界面，不靠删游戏或隐藏大部分库来减轻负担。

目前实测账号约四万款游戏、271 个合集。没有统一的“多少款开始卡”的分界；库规模、动态合集、客户端版本和资料状态都会影响体验。小库未必有可感知收益。

本工具针对 Steam 界面，不承诺提高游戏 FPS、缩短游戏加载时间，或让整个系统秒开。

## 做了哪些优化

- 资料推送时保留客户端的变化判断，减少未变化条目的重复重建。
- 动态合集、网格和数量标签的一次更新共用筛选结果，减少重复读取设置、排序和临时对象。
- 合集封面只计算实际需要展示的预览；通过 Steam 原有响应式机制随资料和筛选变化更新。
- 减少界面配色匹配的重复开销，保留原颜色、封面和网格缓冲排数。
- 修复混排名称列表长按时进入不适用的字母快速跳转，以及部分合集滚动后焦点找不到下一行的问题。
- 商店资料请求对初始化的等待最多 8 秒；晚到的数据仍正常更新，其余必要初始化照常完成。

不修改游戏、存档、合集定义、代理、系统功耗或只读系统分区；不安装自动结束 Steam 的守护程序。

## 兼容性与 Steam 更新

支持原生 SteamOS 的 Steam Deck；安装界面使用系统自带 Python 3、KDE 和用户级 systemd。Windows、macOS、Flatpak Steam 和其他 Linux 发行版未支持。

当前完整实机验证的 Steam 客户端为 **1791918634**。包内保留 **1788652215** 的旧适配，但该客户端没有使用本次单文件安装器重新进行整套实测。

工具按完整方法和依赖指纹识别代码，**未知客户端、冲突或部分修改会停止，不会强套旧补丁**。其他界面修改工具可能冲突；未验证 Decky/CSS Loader 的组合兼容性。

安装后，普通待机、重启、关机不会删除用户目录中的安装记录。游戏模式启动前检查一次；相关 Steam UI 文件变化后也会检查。兼容内容被更新覆盖时重新应用，Steam 正在启动或更新时暂缓。

这些检查使用文件事件，空闲时没有定时轮询，不自动下载补丁或自动重开 Steam。未知更新需要等待适配版本；不承诺兼容所有未来更新。文件已经补回而界面仍在使用旧代码时，需要再正常重开 Steam 才会加载。

## 已完成的实机检查

以下界面实测针对同一性能补丁的 **0.4.12**，不能推广成所有 Deck 和账号的保证：

| 项目 | 本机结果 |
|---|---|
| 向下单按 | 重启前后四个主要页面共 32 次，均移动 |
| 连续长按 | 全部游戏、收藏、已安装、合集均持续移动，结束时焦点可见 |
| 切页和滚轮 | 肩键切页正常；三页真实鼠标滚轮均滚动 |
| 两次实际待机 | 约 25 秒、76 秒后，恢复检测起约 0.73 秒、0.91 秒测到有效输入 |
| 真正系统重启 | 自动加载补丁，主页及 271 个合集正常载入 |
| 覆盖、卸载和重装 | 同客户端文件覆盖后约 1.97 秒补回；卸载恢复原文件，再装恢复补丁 |

局部计数计算在一次实值对照中约从 636ms 降至 144ms，包含一次共享视图创建。这个数字只代表对应计算，不是整个界面的提速比例。开机没有同条件原版对照，不能据此宣称开机已显著提速。

**已知限制**：合集仍偶发约 200–333ms 长帧；76 秒待机那轮第一下未移动，第二下起正常。更早出现过一次实体按键和触屏全无响应，原因未确定，本轮未复现。长时间、游戏运行中待机、换网和更多设备未完成验证。目前不称“零卡顿”或“绝对稳定”。

## 查看状态与卸载

打开桌面的 **Steam 大库优化**，选择：

- **查看状态**：检查磁盘上的当前 Steam 文件是否含兼容补丁。它不能证明尚未重开的界面已经加载。
- **检查更新**：查找 GitHub 新版，确认并校验下载后安装，保留原始备份；下载失败不会改动当前安装。
- **安装 / 修复此版本**：应用当前安装器所带的版本，不会联网获取新版本。
- **卸载并恢复**：移除自动检查，恢复仍与本工具修改记录一致的原文件。然后正常重开 Steam。

卸载不删除原始备份。遇到 Steam 后续更新或其他人的修改，保留现场并提示冲突，不覆盖这些内容。成功安装后不需要保留下载文件才能卸载。

若桌面入口丢失，可重新打开同版本单文件安装器，恢复入口。命令行备用入口仅供排错：

```sh
python3 ~/.local/share/steam-large-library-fix/versions/0.4.16/install.py --uninstall
```

## 数据与排错

安装代码保存在 `~/.local/share/steam-large-library-fix/versions/`；原始备份、状态和本地安装日志保存在 `~/.local/state/steam-large-library-fix/`。临时解包目录会在安装器退出后清理。

工具不读取 Steam 密码、Cookie 或 API key，不上传日志，不收集账号资料。仅点击“检查更新”时连接 GitHub 下载发布版本。备份会包含这台设备原有的 Steam UI 程序，请不要把整个状态目录上传到 GitHub。

遇到问题请记录 Steam 客户端版本、操作步骤、是否能重开 Steam 恢复，以及桌面状态提示。不要提供账号密码或完整私人目录。

## 源码、构建和校验

`-source.zip` 提供安装器源码及许可。解压后可构建相同的离线安装文件：

```sh
python3 src/build_release.py --output ./dist
```

`SHA256SUMS` 列出安装文件和源码包的校验值。安装器内部也检查所带文件的完整性；这用于发现损坏，不能替代从可信发布页下载。
